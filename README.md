
# Application Python de gestion des tâches

## Description
Ce projet est une application simple en Python qui permet de gérer des tâches quotidiennes depuis la console.

## Fonctionnalités
- Ajouter une nouvelle tâche.
- Refuser les titres vides.
- Afficher la liste des tâches avec leur numéro.
- Rechercher une tâche à partir d'un mot-clé.
- Quitter le programme.

## Étapes réalisées
1. Création du fichier `main.py`.
2. Création d'une liste pour stocker les tâches.
3. Mise en place d'un menu avec une boucle `while`.
4. Ajout de la fonctionnalité d'ajout des tâches.
5. Ajout de l'affichage des tâches.
6. Ajout de la recherche par mot-clé.
7. Gestion des erreurs et de la saisie vide.

## Exécution du programme
1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File**.
4. Utiliser le menu affiché dans la console pour gérer les tâches.

## Technologies utilisées
